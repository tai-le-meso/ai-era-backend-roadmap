What I learn
Explaining the frameworkBeing able to narrate what Spring does between your controller returning and the HTTP response being written — message converters, content negotiation, the filter chain unwinding — is a senior-level explanation few people can give.
Calibrating trust in AIThis drill is specifically about measuring vagueness. Every point where the model hand-waves is a point where you would have been misled had you not known better. That calibration number is the input to your Phase 7 human-responsibilities policy.
What I do
  1. Finish and tag v0.
  2. Write the Reason answer: the full request path with every proxy and filter named.
  3. Run the AI drill and log every vague or wrong point.
  4. Compile the week's 'AI got it wrong' list — you need at least five entries by the phase gate.
What I conclude
  • Reason (write it out): draw the request path from HTTP socket to your repository method, naming every proxy and filter it passes through.
  • AI drill: ask AI to explain what Spring does between the controller returning and the HTTP response being written. Verify against the actual reference docs and log every vague or wrong point.
  • This calibration exercise is the seed of the whole AI-judgment thread — you cannot decide how much to delegate until you have measured where the model is weak.
